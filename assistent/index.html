Curiosa Skoleassistent

1-klikks oppgavegenerator, strukturert pensum-PDF og lesestøtte for Chrome

Curiosa Skoleassistent v1.0.0

Den offisielle Chrome-utvidelsen for Curiosa. Gjør enhver nettside eller fagartikkel om til skreddersydde flervalgs-, hulltekst-, sorterings- og refleksjonsoppgaver med KI, eller generer strukturerte pensum-PDF-er rett inn i elevenes fagstoffarkiv.

1-Klikks Oppgaver

Forvandle artikler på NRK, NDLA og SNL til fagoppgaver direkte i dine Curiosa-temaer.

Pensum-PDF

Lag lekre, strukturerte PDF-er med figurer og overskrifter for elevenes notatarkiv.

Lesestøtte

Dobbeltklikk på vanskelige ord på en hvilken som helst nettside for synonymer og opplesing.

Legg til i Chrome (Chrome Web Store) Last ned .ZIP (v1.0.0) 📖 Brukerveiledning

Installasjon:

1
Fra Chrome Web Store (Kommer snart): Trykk på den grønne knappen over for 1-klikk-installasjon med automatiske oppdateringer i nettleseren.
2
Manuell installasjon (ZIP nå): Last ned curiosa-skoleassistent.zip, pakk ut mappen, åpne chrome://extensions i Chrome, slå på Utviklermodus øverst til høyre, og trykk «Last inn uemballert».
